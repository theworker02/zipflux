# zipflux

Zip URLs and flux query parts with stable normalization.

**Site:** https://theworker02.github.io/zipflux/

## Install / run

```bash
git clone https://github.com/theworker02/zipflux.git
cd zipflux
node src/cli.js
node --test
```
